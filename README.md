# Hitory Worship 홈페이지

히토리 워십의 공식 웹사이트입니다.

## 프로젝트 구조

```
hitoryworship/
├── index.html        # 메인 HTML 파일
├── css/
│   └── style.css    # 스타일시트
└── images/          # 이미지 파일 디렉토리
```

## 기능

- 반응형 디자인
- 모던한 UI/UX
- 예배 시간 안내
- 교회 소개
- 예배 일정
- 연락처 정보

## 설치 및 실행

1. 저장소를 클론합니다:
```bash
git clone [repository-url]
```

2. 웹 브라우저에서 index.html 파일을 엽니다.

## 커스터마이징

1. 이미지 변경:
   - `images` 디렉토리에 원하는 배경 이미지를 `worship-bg.jpg`로 추가합니다.

2. 내용 수정:
   - `index.html` 파일에서 텍스트 내용을 수정합니다.
   - 연락처 정보를 업데이트합니다.

3. 스타일 수정:
   - `css/style.css` 파일에서 색상, 폰트 등을 수정할 수 있습니다.

## 기술 스택

- HTML5
- CSS3
- Google Fonts (Noto Sans KR)
